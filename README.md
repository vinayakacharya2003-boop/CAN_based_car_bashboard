# CAN_based_car_bashboard
A real-time embedded automotive dashboard system developed using the Controller Area Network (CAN) protocol for communication between multiple Electronic Control Units (ECUs). This project demonstrates how automotive peripherals such as sensors, switches, LEDs, and display modules can be integrated and monitored through CAN-based communication.
Features
CAN communication between multiple ECUs
Real-time vehicle parameter monitoring
Sensor data acquisition and processing
OLED/LCD dashboard display interface
LED indicators and warning system
Switch-controlled functionalities
Embedded C firmware development
Reliable message transmission using CAN protocol
Modular and scalable ECU architecture
Technologies Used
Embedded C
CAN Protocol
Microcontrollers
Sensors and Display Modules
